# 第三方软件说明

LocalProject Desktop 包含以下开源软件。对应许可证全文会随 macOS 应用一起安装在 `LocalProject.app/Contents/Resources/licenses/`。

| 软件 | 用途 | 许可证 |
| --- | --- | --- |
| Electron | macOS 桌面运行时 | MIT；同时包含 Chromium 第三方组件说明 |
| Vue | Renderer 界面框架 | MIT |
| Phosphor Icons | Renderer 图标 | MIT |

LocalProject 自身依据仓库根目录的 MIT License 发布。构建与测试依赖的完整版本记录在 `desktop/pnpm-lock.yaml` 中。
